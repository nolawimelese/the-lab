# The Lab

A personal lab of experiments, code snippets, and mini projects — for testing ideas, learning new concepts, and building proof of concepts.

## Structure

Top-level folders are domains, a few are split into sub-domains.

The deepest folder is always one self-contained experiment, with its own README.

```
.
├── web/                          Web development (frontend & backend)
├── data/
│   ├── ml/                       Machine learning
│   ├── data-eng/                 ETL / ELT pipelines
│   └── data-science-handbook/    Working through the Python Data Science Handbook
├── low-level/
│   └── c/                        C projects
└── misc/                         Anything that doesn't fit neatly elsewhere
```
